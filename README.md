# TA Miners Reloaded

Big miners inspired by the Total Annihilation metal extractors. Adds 3 tiers of massive miners
(Crust, Moho and Mantle Extractor) that can mine entire ore patches.

This is a continuation of TA Miners for Factorio 2.1, with working Krastorio 2 recipes.

## Changes in this version

- Factorio 2.1 support
- Krastorio 2: recipes use the current Krastorio 2 items, the miner technologies require the matching Krastorio 2 technologies,
  and the Krastorio 2 recipe setting is enabled by default when Krastorio 2 is installed
- Fixed a crash when a modded recipe set was applied on top of the vanilla recipe
- Fixed the German translation

Saves that use "TA Miners" (WipMod_TA-miners) keep their miners: disable the old mod and enable this one, the entity names are unchanged.
